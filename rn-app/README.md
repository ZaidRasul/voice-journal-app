React Native voice journal (starter)

Quick start

1. Install dependencies (use yarn or npm):

   yarn install

2. Android
   - Start Metro: `yarn start`
   - Run on device/emulator: `yarn android`

Notes
- Vosk model: copy the model folder into `android/app/src/main/assets/models/` for Android.
- I pinned `react-native`/`react` versions to avoid incompatibilities. Adjust the `vosk-react-native` version if you have a preferred release.
