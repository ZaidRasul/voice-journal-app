VOICE JOURNAL — FEATURE GUIDE
=============================

Purpose
-------
Voice Journal is a lightweight, native Android note-taking app. It keeps notes
on the phone in a small SQLite database and uses the Android device's installed
speech recognizer instead of bundling a large speech model.

What users can do
-----------------
1. Create a note from the Notes screen.
2. Rename, edit, save, reopen, and delete notes at any time.
3. Mix several block types in the same note:
   - Plain text
   - Bulleted list items
   - Numbered list items
   - Checkboxes / checklist items
4. Give each block a text style:
   - Body
   - Heading
   - Subheading
   - Quote
5. Reorder or remove individual blocks while editing.
6. Tap “Speak to this note” to dictate text into the note currently open.
7. Tap “Voice command” on the Notes screen to route speech to a named note.
8. Use Rant mode for a live, continuously appended transcript. Rant mode never
   interprets speech as a command. Its text can be saved as a normal note.

Voice-command examples
----------------------
The clearest global command format is:

  add to Groceries: checkbox milk
  add to Weight log: numbered 72 kilograms
  put buy basil in Groceries
  append remember the meeting into Work

The words “checkbox”, “bullet”, “numbered”, and “text” at the start of the
content choose a block type. Content without one of those words becomes a plain
text block. If a named note does not exist, Voice Journal creates it, then adds
the dictated block.

Daily and weekly list ideas
---------------------------
• A “Daily weight” note can contain dated numbered entries.
• A “Groceries” note can contain checkbox items and ordinary reminders.
• A “Weekly plan” note can mix a heading, bullet items, numbered steps, and
  checkboxes in a single note.

Privacy and voice behavior
--------------------------
Only text is saved; the app does not record or keep raw audio. The installed
Android speech service performs recognition. The app prefers on-device
recognition where the phone supports it, but some devices may use their chosen
speech service and network. Microphone access is requested only after the user
taps a voice control. Rant mode stops when the app leaves the foreground.

Storage and size
----------------
The baseline intentionally has no Flutter runtime, cloud SDK, ads, analytics,
or bundled Vosk/Whisper model. Notes are stored in the app's private SQLite
database and are eligible for the user's normal Android backup settings.

Technical baseline
------------------
Language: Kotlin 2.3.21
Android Gradle Plugin: 8.13.2
Gradle: 8.13
JDK / JVM target: 17
compileSdk / targetSdk: 36
minSdk: 26 (Android 8.0)

This combination is deliberately pinned to a compatible Android 16-era toolchain
and avoids APIs that are deprecated in this codebase.
