VOICE JOURNAL — FEATURE GUIDE
=============================

Purpose
-------
Voice Journal is a lightweight, native Android journaling app. It keeps journals
on the phone in a small SQLite database and uses the Android device's installed
speech recognizer instead of bundling a large speech model.

What users can do
-----------------
1. Create named journals from the Journals screen. Untargeted voice entries go
   to an always-available “Default Journal”.
2. Rename, edit, save, reopen, and delete journals at any time.
3. Mix several entry types in the same journal:
   - Plain text
   - Bulleted list items
   - Numbered list items
   - Checkboxes / checklist items
4. Give each entry a text style:
   - Body
   - Heading
   - Subheading
   - Quote
5. Reorder or remove individual entries while editing.
6. Tap “Speak to this journal” to dictate into the journal currently open.
7. Tap “Voice command” on the Journals screen to route speech to a named journal.
8. Use Brain Dump for a live, continuously appended transcript. Brain Dump never
   interprets speech as a command. It keeps listening in the background until
   the user taps Stop, and its text can be saved as a normal journal.
9. Search journal names and entry text from the Journals screen.
10. Every journal entry carries its own creation date and time.
11. Ask to retrieve a journal or analyze its numeric entries:

  show me all entries from weight journal
  how has my weight changed over the last month?

12. Open Trend on any journal to see numeric measurements, change, minimum,
    maximum, and a time-series graph. The first number in each entry is treated
    as that entry's measurement.

Voice-command examples
----------------------
The clearest global command format is:

  add to Groceries: checkbox milk
  add to Weight log: numbered 72 kilograms
  add to Weight 72 kilograms
  put buy basil in Groceries
  append remember the meeting into Work

The words “checkbox”, “bullet”, “numbered”, and “text” at the start of the
content choose a block type. Content without one of those words becomes a plain
text entry. Target-first commands without a colon are matched against all journal
names currently stored on the phone. If a colon-labelled named journal does not
exist, Voice Journal creates it, then adds the dictated block. Command capture
waits about four seconds after the latest recognized phrase, so a short thinking
pause does not submit an incomplete command. Incomplete or unresolved command
phrases are not saved into Default Journal.

Daily and weekly list ideas
---------------------------
• A “Daily weight” journal can contain automatically dated numbered entries.
• A “Groceries” journal can contain checkbox items and ordinary reminders.
• A “Weekly plan” journal can mix a heading, bullet items, numbered steps, and
  checkboxes.

Privacy and voice behavior
--------------------------
Only text is saved; the app does not record or keep raw audio. The installed
Android speech service performs recognition. The app prefers on-device
recognition where the phone supports it, but some devices may use their chosen
speech service and network. Microphone access is requested only after the user
taps a voice control. Ordinary commands stop when complete or when the app leaves
the foreground. Brain Dump uses an Android microphone foreground service, keeps
an ongoing notification with a Stop action, and continues until the user stops it.

Storage and size
----------------
The baseline intentionally has no Flutter runtime, cloud SDK, ads, usage tracking,
or bundled Vosk/Whisper model. Journals are stored in the app's private SQLite
database and are eligible for the user's normal Android backup settings.

Technical baseline
------------------
Language: Kotlin 2.3.21
Android Gradle Plugin: 8.13.2
Gradle: 8.13
JDK / JVM target: 17
compileSdk / targetSdk: 36
minSdk: 26 (Android 8.0)

This combination is deliberately pinned to a compatible Android 16-era toolchain
and avoids APIs that are deprecated in this codebase.
